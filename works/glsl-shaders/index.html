GLSL Shaders

Portions of OpenGL’s graphics pipeline, programmed by hand: a set of vertex and fragment shaders that apply different coloration effects to the surfaces of 3D models.

  • Rendering
  • GLSL
  • OpenGL
  • C++
  • Shader Programming
  • Post-Processing
  • Source code
Year
2023
Built with
GLSL, OpenGL, C++

Overview

  • Surface shaders: Lambert, Blinn-Phong, matcaps, surface normals and a colour gradient
  • Vertex deformation
  • Post-process shaders: greyscale, Gaussian blur, Sobel edge detection, bloom and Worley noise
