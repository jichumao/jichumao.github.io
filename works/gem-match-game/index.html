Gem Match Game

A classic gem puzzle game written in C++ with Qt Widgets and the Easy2D game engine.

Overview

In this game, I was responsible for creating the game animations, developing the game client logic, and contributing to the game’s art design.

For the gem elimination animations, we implemented an animation delay-lock system to ensure that animations play correctly during consecutive eliminations. Chains are found with graph traversal over connected gems.
