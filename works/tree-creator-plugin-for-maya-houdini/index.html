Tree Creator – Plugin for Maya & Houdini

Softwares

This is a Maya & Houdini plugin development project. The function of this plugin is to create different fractal plants in Maya or Houdini based on the L-System grammar input by the user.

I developed two separate plugins, each implementing the same functionality in Maya and Houdini, respectively. This plugin allows users to:

  • Customize the L-System grammar file
  • Customize the Step Size
  • Customize the branch rotation angle
  • Customize the number of iteration steps

Using the above files as parameters, it generates different models in Maya and Houdini.
