Overview

I developed two separate plugins, each implementing the same functionality in Maya and Houdini, respectively. The plugin lets the user customize:

  • The L-system grammar file
  • The step size
  • The branch rotation angle
  • The number of iteration steps

Using these parameters, it generates different models in Maya and Houdini. The two videos show the plugin in each application.

The image at the top of this page is the plugin’s own L-system core run on the grammars that ship with it: five plants, each drawn with its production rule, branch angle δ and iteration count n.
